Deep-Motility eval (dev page, not part of the app)

Serve a directory that contains this repo's web/ and a link to the dataset, e.g. ln -s /path/to/Motilidad data; ln -s /path/to/repo/web web; python3 -m http.server, then open /web/js/deepmotility/eval.html?data=/data/&n=0 (n limits images per set, 0 = all; sets=seg,cls). Latency of single ONNX files with the WASM runtime: ?bench=/m/a.onnx:512,/m/b.onnx:384&auto=1.
